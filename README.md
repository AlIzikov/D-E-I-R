# D-E-I-R — ИИ-Учитель

Проект автономного ИИ-наставника по системе ДЭИР.

## Цель проекта

Создать систему ИИ-агентов, которая изучает материалы, проверяет их качество, формирует базу знаний и отвечает пользователю на основе сохранённых источников.

## Архитектура

- **Учитель (Coordinator)** — управляет агентами, проверяет их отчёты и формирует итоговый ответ.
- **Библиотекарь-поисковик (Researcher)** — ищет подходящие источники и готовит материалы для проверки.
- **Проверяющий-систематизатор (Reviewer)** — оценивает качество, достоверность и релевантность материалов.
- **Developer** — разрабатывает и поддерживает код проекта.
- **Auditor** — проверяет код и сообщает о найденных проблемах.

## Основные правила

1. Не выдумывать факты и не приписывать источникам неподтверждённые сведения.
2. Отвечать на основе утверждённой базы знаний.
3. Если ответа нет в сохранённых материалах, сообщать: «В сохранённых материалах ответа нет».
4. Добавлять материалы в базу знаний только после проверки и решения Учителя.
5. Обмен между Developer и Auditor организовать через файлы в GitHub.
6. Не хранить API-ключи, пароли и токены в репозитории.
7. Не загружать книги и другие материалы без разрешения на их хранение.
